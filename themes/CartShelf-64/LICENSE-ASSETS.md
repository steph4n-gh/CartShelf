# CartShelf-64 asset licenses

The menu font atlas is named CartShelf Menu. `build_theme.py` creates it from the unmodified Silkscreen Bold font and original geometric control glyphs. The atlas does not contain the vendor theme tool's font bitmap.

Silkscreen and the derived CartShelf Menu atlas, including its geometric control glyphs, use the SIL Open Font License 1.1. Copyright 2001 The Silkscreen Project Authors. Keep `source/OFL.txt` with the fonts and packages containing them. The original font project is <https://github.com/googlefonts/silkscreen>.

CartShelf's generated wallpaper, branding pixels, configuration, generator, and verification code use the repository's GPL-3.0-only license. The generated BGR combines those assets with the OFL font atlas. Its font license remains OFL-1.1.

The previews use authored fictional game names and generated graphics. They contain no ROM data, game artwork, firmware, vendor font, or console screenshot. Every preview is a simulation. This replacement atlas has not been tested on a physical cartridge.
