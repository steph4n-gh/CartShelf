# Documentation images

`cartshelf-banner.svg` is original CartShelf artwork. Its pixel letters and cartridge shapes are authored vector geometry. `cartshelf-social.png` is a 1280 by 640 render of that SVG made with macOS `sips`. Both use GPL-3.0-only and contain no external fonts or images.

`library-browser.jpg`, `system-files.jpg`, and `recipe-review.jpg` are fresh captures of 0.7.0-beta.1 build 17 using a distinct documentation bundle ID, an isolated generated-data library, and disabled preference persistence. The app source and bundled services are unchanged. The recipe view was cancelled after inspection. No card was written.

`pack-builder.jpg` and `save-timeline.jpg` show the actual 0.7.0-beta.1 build 16 app. Build 17 keeps the same layout and media/save behavior, with a Swift compiler compatibility correction. All app screenshots use fictional titles and generated, nonplayable game and save fixtures. They contain no personal collection, retail game artwork, ROM bytes, save bytes, firmware payload, credentials, or personal paths. Game and save checksums identify generated fixtures. The System Files screenshot displays the public stock OS checksum.

`review-card.jpg` shows an authored display-only fixture using the production review view. Startup and installation are disabled. It illustrates the layout and does not demonstrate a physical card operation.

`gb-palette.svg` is an original reference illustration of the four source colors in `themes/CartShelf-GB/apply_theme.py`. It uses authored rectangles and text with a generic monospace font, contains no external assets, and uses GPL-3.0-only. It is not a console capture or a simulated menu.

The N64 menu and popup images linked from the guides are existing labelled simulations under `themes/CartShelf-64/preview`. They use fictional game names and original theme geometry. See [theme asset licensing](../../themes/CartShelf-64/LICENSE-ASSETS.md). Their public font atlas still needs physical cartridge qualification.

The screenshots are CartShelf project documentation under GPL-3.0-only. The app's Silkscreen font retains its [SIL Open Font License](../../app/Resources/OFL.txt). Cartridge and console names describe compatibility. CartShelf is an independent project.
